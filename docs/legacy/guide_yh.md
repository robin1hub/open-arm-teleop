# 历史零位校准指南（原按 OpenArm 2.0 误判）

> **历史文档警告（2026-07-28）：** 当前实机已确认为 OpenArm 1.0。
> 本文的 v2 治具姿态和 offset 说明不适用于当前实机，不得据此再次写零位。
> 当前有效配置和检查流程见 `INTERACTIVE_CONTROL.md`。

本文记录本机 OpenArm 2.0 双臂的零位校准前提、操作顺序和验收方法。

## 1. 官方参考文档

- [Motor Configuration](https://docs.openarm.dev/software/setup/motor-config/)
- [Setup Tutorial](https://docs.openarm.dev/tutorial/setup/)
- [OpenArm CAN CLI](https://docs.openarm.dev/api-reference/can/cli/)

执行前应再次对照官方文档，确认当前安装版本的命令参数没有变化。

## 2. 当前设备映射

本机已经确认的连接关系为：

| 机械臂 | Linux CAN 接口 | 电机 CAN ID |
|---|---|---|
| 右臂 | `can0` | `1`～`8` |
| 左臂 | `can1` | `1`～`8` |

两侧均使用 CAN-FD，仲裁域速率为 1 Mbps，数据域速率为 5 Mbps。每次交换
USB-CAN 接口后都必须重新核对映射。

## 3. 零位校准的含义

`set_zero` 不是命令机械臂自动运动到零位，而是把电机当前所在的物理姿态记录为零位参考。

如果机械臂摆放姿态不准确，校准后会出现以下问题：

- 实机关节角与 MuJoCo 模型不一致；
- IK 计算得到的姿态与实机姿态不一致；
- 关节运动方向、限位和初始对齐异常；
- 启动整臂控制时可能突然运动或发生碰撞。

因此，没有确认 OpenArm 2.0 官方零位姿态或安装好官方零位治具时，不得执行 `set_zero`。

## 4. 校准前安全检查

必须同时满足以下条件：

- 机械臂底座已经牢固固定；
- 工作空间内没有人员和障碍物；
- 急停或总电源开关触手可及；
- 机械臂已可靠支撑，断使能后不会下坠；
- 已确认使用 OpenArm 2.0 对应的官方零位姿态或零位治具；
- 左右臂的 CAN 接口映射已经复核；
- 没有运行 Dora、遥操作、轨迹控制或其他可能发送 CAN 指令的进程；
- 电机无未处理的错误状态，CAN 总线处于 `ERROR-ACTIVE`；
- 先校准一条手臂并验收，再校准另一条手臂。

校准可能伴随电机动作。机械臂附近必须留出安全距离，不能用手强行阻挡运动。

## 5. 校准前只读检查

首先检查接口状态：

```bash
ip -details -statistics link show can0
ip -details -statistics link show can1
```

然后用 OpenArm 官方工具读取参数，确认每侧 ID `1`～`8` 都能稳定响应。具体查询参数以当前版本帮助信息为准：

```bash
openarm-can-cli --help
openarm-can-cli -i can0 show_param --help
```

不要在此阶段执行 `enable`、运动指令或批量写参数。

## 6. 摆放零位姿态

1. 断使能，并对机械臂进行可靠支撑。
2. 安装 OpenArm 2.0 官方零位治具，或严格按照官方图示摆放各关节。
3. 检查每个关节的机械方向，不要只根据外观估计零位。
4. 确认夹爪所要求的零位状态；夹爪是否与 7 个关节一同设置必须以当前官方文档和 CLI 行为为准。
5. 拍照记录左右臂校准姿态，以便后续排查。

如果官方资料没有给出足够清晰的零位姿态，应先向 OpenArm 官方确认，不要自行定义一个“看起来对称”的姿态。

## 7. 执行零位校准

先查看当前 CLI 的准确语法：

```bash
openarm-can-cli -i can0 set_zero --help
```

确认姿态、安全条件和命令范围后，按照官方文档对单侧接口执行。例如，当前映射下左臂接口为：

```bash
sudo openarm-can-cli -i can0 set_zero
```

右臂接口为：

```bash
sudo openarm-can-cli -i can1 set_zero
```

注意：上述命令仅用于说明本机接口对应关系。实际执行前必须确认当前版本是按整条总线设置，还是需要逐个指定电机 ID。禁止在两条手臂未摆好标准姿态时连续执行两条命令。

推荐顺序：

1. 只连接或只操作一条手臂；
2. 读取 ID `1`～`8`，保存校准前状态；
3. 摆好并固定标准零位姿态；
4. 执行该侧 `set_zero`；
5. 重新上电；
6. 只读检查并完成该侧验收；
7. 确认完全正常后再处理另一侧。

## 8. 校准后验收

校准后不要立即运行整臂轨迹或 VR 遥操作。依次完成：

1. 重新上电，保持机械臂受支撑；
2. 检查 CAN 接口状态和错误计数；
3. 使用官方工具确认 ID `1`～`8` 全部响应；
4. 读取当前关节位置，确认与官方零位定义一致；
5. 手动改变一个关节少量角度，再读取反馈，确认符号和变化方向正确；
6. 在安全条件下，对单个关节进行极小幅、低速运动测试；
7. 比较实机和 MuJoCo 中同一关节的方向与姿态；
8. 完成一条手臂全部关节验收后，再测试另一条手臂；
9. 最后才进行单臂轨迹、双臂轨迹和遥操作。

第一次主动运动建议每次只测试一个关节，目标变化量控制在约 `0.01～0.03 rad`，并设置低速度、关节限位、单步变化限制、通信超时停止和急停保护。

## 9. 立即停止的异常

出现以下任一情况时立即停止测试并断使能：

- 上电后机械臂突然运动；
- 关节反馈出现 `NaN`、`Inf` 或明显跳变；
- 实际运动方向与 MuJoCo 相反；
- CAN 接口进入 `ERROR-PASSIVE` 或 `BUS-OFF`；
- 某个 ID 无响应或出现重复响应；
- 电机异常发热、振动或发出异常声音；
- 机械位置与读取角度明显不符；
- 夹爪或关节接近机械硬限位。

## 10. 完成判定

只有满足以下条件，才能认为零位校准完成：

- 右臂 `can0` 和左臂 `can1` 的 ID `1`～`8` 均稳定响应；
- 机械臂处于官方零位姿态时，反馈值符合官方定义；
- 所有关节的反馈符号、运动方向和 MuJoCo 模型一致；
- 重新断电上电后零位仍然有效；
- 单关节小幅测试没有跳变、超限或 CAN 错误；
- 校准日期、姿态照片、工具版本和验收结果已经记录。

在以上验收完成前，禁止连接 VIVE 执行真实机械臂遥操作。
