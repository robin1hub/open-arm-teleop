# OpenArm 1.0 MuJoCo 拖动与实体控制

当前实机已经确认是 OpenArm 1.0。程序默认加载项目内固定的官方 v1 MJCF：
`models/openarm_v1/scene.xml`。不得使用已安装 Python 包中的 v2 Cell 模型控制
这台机械臂。

## 迁移记录（2026-07-28）

最初按 OpenArm 2.0 配置时，实机标定姿态与 MuJoCo 出现明显差异：实机双臂
接近下垂，但仿真双臂向内蜷缩。最终通过夹爪结构和官方模型对比，确认实体硬件
是 OpenArm 1.0：

- v1 使用平行连杆/滑轨夹爪；
- v2 使用紧凑型 pinch gripper，并采用不同末端模型；
- 当时本机只安装了 `openarm-mujoco 2.0.0`，因此程序一直加载错误模型。

完成的迁移工作：

- 从 Enactic 官方 `openarm_mujoco` 仓库固定 v1 MJCF 与 mesh 到
  `models/openarm_v1/`；
- `interactive_mujoco_ee_drag.py` 增加 `--model-version v1|v2`，默认 `v1`；
- v1 末端控制帧改为 `openarm_right_hand_tcp` /
  `openarm_left_hand_tcp`，类型为 MuJoCo body；
- 保留原有双臂选择、鼠标拖动、相机控制、目标限速和 IK 安全过滤；
- 新增 v1 实机只读检查 `verify_real_mujoco_alignment_v1.py`；
- 实体启动脚本固定传入 `--model-version v1`；
- 单独处理 v1 夹爪的电机转角与 MJCF 滑块位移单位差异。

固定模型来源为官方仓库提交
`8955afb54e4adfb59a236e2b4d15192b7a02865c`（2026-07-27），许可证保存在
`models/openarm_v1/LICENSE`。

## 当前接口映射

- 右臂：`can0`
- 左臂：`can1`
- 交互实体控制配置：`openarm_safe_raw_zero.yaml`

本机电机是在双臂基本竖直下垂、对应 MuJoCo `qpos=0` 的姿态写入零位，
因此该配置的 `joint_offsets` 为全零。不得改回官方 Cell 治具使用的 offset，
否则仿真会表现为双臂向内蜷缩，反向控制指令也会使用错误坐标。

每次接线变化后都必须重新检查接口映射，不得只依据 USB 插入顺序推断。

## 1. 纯仿真模式

启动：

```bash
cd /home/robin/open_arm
.venv/bin/python interactive_mujoco_ee_drag.py
```

纯仿真模式不会创建 OpenArm 实机驱动，也不会访问 CAN。
等价的显式命令为：

```bash
.venv/bin/python interactive_mujoco_ee_drag.py --model-version v1
```

## 2. 实体机械臂模式

清空工作空间、固定底座并确保急停触手可及，然后启动：

```bash
cd /home/robin/open_arm
./run_interactive_real.sh --confirm-hardware
```

启动流程：

1. 检查 `can0`、`can1` 均存在且为 `UP`；
2. 只读获取双臂关节反馈；
3. 检查反馈稳定、数值有限且位于配置关节限位内；
4. 用实机关节位置初始化 MuJoCo 和 IK；
5. 打开窗口，保持两条机械臂失能。

启动实体模式前可执行只读映射检查：

```bash
.venv/bin/python verify_real_mujoco_alignment_v1.py
```

程序不会自动把实机移动到 MuJoCo `home`。必须先确认画面姿态和实机姿态一致，
再使能机械臂。

程序在启动时读取一次双臂实机姿态，并用它初始化 MuJoCo。此后仿真目标可独立
拖动，实体机械臂不会自动跟随；按 `D` 才会执行当前仿真姿态。

## 3. 机械臂选择与目标操作

- `1`：选择左臂；
- `2`：选择右臂；
- `Tab`：切换活动臂，实体模式下会先失能原活动臂；
- 左键拖动：在当前视图平面移动活动臂目标；
- `Shift + 左键`：屏幕水平方向以及世界坐标 Z 方向移动；
- 右键拖动：旋转末端目标姿态；
- `R`：把目标恢复到活动臂当前末端位置；
- `Space`：暂停或恢复 IK；
- `Esc`：退出，实体模式下同时失能机械臂。

较大的彩色坐标架表示活动臂目标；较小的半透明坐标架表示非活动臂。
绿色表示 IK 正常，红色表示目标不可达或跟踪误差过大。

## 4. 视角操作

- `Alt + 左键`：旋转视角；
- 中键拖动：平移视角；
- 滚轮：缩放。

## 5. 实体模式使能与慢速控制

- `E`：使能或失能当前选择的机械臂；
- 单击 `D`：让当前已使能的实体机械臂慢速移动到当前仿真关节位置；
- 到达后停止更新位置指令，电机保持目标位置；
- 切换活动臂、关闭窗口或程序异常退出：失能当前机械臂。

`D` 是一次性的“执行当前仿真姿态”命令，不需要持续按住。仿真目标不可达或
IK 尚未收敛时，程序会拒绝执行。窗口失去焦点时会取消尚未完成的移动。

初始实体限速：

- 指令频率：`20 Hz`；
- 每周期最大关节变化：`0.003 rad`；
- 等效单关节最大速度约：`0.06 rad/s`，即 `3.4°/s`。

该限速位于交互程序中；驱动内部的关节绝对限位和相邻指令增量保护仍同时生效。

OpenArm 1.0 实体夹爪反馈是电机转角，而 MJCF 使用 0–44 mm 直线滑块。当前界面
尚未提供夹爪目标操作，因此按 `D` 时只执行 J1–J7，夹爪保持当前物理角度。

纯仿真：

- v1 左右臂均完成从下垂零位向前 4 cm 的平滑笛卡尔轨迹；
- 左右臂末端位置误差均约 `1.83 mm`；
- 姿态误差约 `0°`；
- 最大单步关节变化约 `0.00092 rad`；
- v2 回归测试仍通过，证明版本选择没有破坏旧模型入口。

只读实机：

- `can0`、`can1` 均为 CAN-FD、`UP`、`ERROR-ACTIVE`；
- 当前映射为右臂 `can0`、左臂 `can1`；
- v1 J1–J7 实机反馈写入 MuJoCo 后逐项误差为 `0`；
- 当前非零弯肘姿态下，所有 J1–J7 均位于官方 v1 MJCF 关节限位内；
- 实体窗口初始姿态已确认基本与实机一致。

## 7. 当前限制

- 实体夹爪仅保持当前角度，尚未实现从 0–44 mm 仿真开度到左右夹爪电机角度的
  双向标定控制；
- v1 下垂零位接近运动学奇异位形，保持末端姿态不变时不能直接向任意方向平移；
- `D` 目前是单臂、一次性执行仿真关节姿态，不是连续实时跟随；
- VIVE/SteamVR 实体遥操作流程尚未迁移到 v1 模型，迁移前禁止使用旧 v2
  实体 dataflow；
- `openarm_safe_current.yaml` 属于旧 v2/官方 offset 实验配置，不得用于当前
  v1 实体交互；当前入口只使用 `openarm_safe_raw_zero.yaml`。

## 8. IK 安全实现

交互程序使用项目内的 `safe_kinematics.py`，不再直接使用已安装
`openarm_control` 中会在受限求解失败后执行 `limits=[]` 的回退路径。

严格 IK 的规则：

- 每次求解始终携带 MuJoCo 关节限位；受限问题无解时直接拒绝目标；
- 每周期以当前关节角作为姿态正则目标，优先选择离当前姿态最近的冗余解；
- 积分结果逐关节再次检查硬限位；
- 仅将小于 `1e-5 rad` 的边界浮点噪声夹回限位；
- 任一关节单次求解变化超过 `0.06 rad` 时，判定为分支跳变并回滚；
- `D` 执行前，任一关节相对实机变化不得超过 `0.35 rad`，J1–J7 变化向量范数
  不得超过 `0.7 rad`，更大的动作必须分段。

末端任务同时包含位置误差和朝向误差。姿态权重决定求解器为了保持/改变夹爪
方向，愿意让多少关节参与补偿：

- 普通左键平移：姿态权重 `0.15`，位置优先，允许少量朝向误差以减少绕肘、
  翻腕和多余关节动作；
- 右键旋转及其后约 `0.3 s`：姿态权重 `1.0`，严格跟随用户指定的末端朝向；
- 非活动臂：姿态权重 `1.0`，保持其当前末端位姿。

OpenArm 1.0 双臂下垂零位接近运动学奇异位形。在该姿态保持夹爪方向完全不变时，
部分笛卡尔方向本来就不可达；目标变红或被拒绝属于正确行为，不应通过取消限位
强行求解。

## 9. 首次实体操作顺序

1. 启动实体模式，但不要按 `E`；
2. 比较 MuJoCo 与实机双臂初始姿态；
3. 按 `1` 或 `2`，只选择一条机械臂；
4. 按 `R`，确保目标位于当前末端；
5. 在仿真中把末端目标拖动约数毫米，等待 IK 收敛；
6. 按 `E` 使能该臂，观察是否保持静止；
7. 单击 `D`，让实机慢速移动到仿真姿态；
8. 检查实机、画面、日志和 CAN 状态；
9. 确认无异常后再逐步扩大范围；
10. 测试结束按 `E` 失能，再按 `Esc` 退出。

发生方向错误、突然运动、振动、异常声音、通信丢失、红灯或接近机械限位时，
立即松开 `D`、按急停，并切断使能。
